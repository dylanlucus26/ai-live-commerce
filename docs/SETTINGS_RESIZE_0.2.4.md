# v0.2.4 设置窗口与 OBS 页面布局修复

- 原因：v0.2.3 高级设置是固定最大宽度的 DOM 弹层，不是独立可拖拽的 macOS/Windows 原生窗口；设置内容的 OBS 控件与视频素材卡片过窄。
- 本次新增窗口左右边缘宽度拖拽手柄，右边向外拖宽、向内拖窄，左边同理；支持方向键精细调整；使用 localStorage 保存上次宽度。
- 设置中心左侧的分类导航与右侧内容之间也增加独立拖拽分隔条，左/右调整分类栏宽度（165 至 350px），并单独记忆。
- 保持主程序 BrowserWindow 可原生拖边缩放，最小宽度降低至 840px；Mac/Windows 系统允许通过原生窗口边缘调整整个应用大小。
- 「画面与 OBS」重排为响应式布局，内容区完全填满容器：空间充足时视频和 OBS 双列，空间不足时自动变成上下排列；视频添加了 16:9 预览、播放列表切换，OBS 控制统一中文。
- 在 Chromium 页面点击自动化中增加拖拽边缘、关闭重新打开恢复宽度、拖拽分类分隔条、视频与 OBS 视图宽度检查；原生 Electron 检查 BrowserWindow 的 isResizable 和最小尺寸。
- CI 仍检查 macOS 签名完整性、真实 Electron IPC、Windows 和 macOS 浏览器渲染，不凭“编译成功”替代 UI 行为验收。

**注意**：设置中心仍是一个覆盖在直播主控台之上的网页弹层，不是额外创建的 macOS 系统独立窗口；调整的是设置中心的面板宽度，并不会改变主程序窗口宽度。主程序本身可从 macOS 窗口边缘单独缩放。
