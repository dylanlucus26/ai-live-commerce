# v0.2.3 设置中心统一改版

## 用户反馈

v0.2.2 的高级设置仍有「原有管理能力」栏，包含六个旧页面跳转入口。与要求的单屏操作台和统一管理不一致。

## 修改

- 删除整个「原有管理能力 / 更多工具」页，用户界面不再暴露白色旧页面跳转卡片。
- 将原有自动回复的细粒度监听来源、WebSocket 与互动事件话术补入 AI 互动。
- 新增「直播连接」：浏览器路径、自动识别、登录状态清理及连接详情。
- 新增「直播任务」：人工许可确认后的定时发言（话术、间隔、随机配置）、商品弹窗（商品编号、频率）与快捷键管理；启动任务默认关闭。
- 新增「软件设置」：检查更新、自动更新提示、打开日志、开发者模式、账号管理和数据清理。
- 将商品弹窗快捷键监听提升到应用根节点，不依赖进入旧页面才能生效。
- 保留历史数据结构和兼容路由（只隐藏日常界面入口，不删除旧业务代码），确保已有账号、商品、话术、音频数据不被清空。

## 验收

Windows 与 macOS：类型检查、Node 回归测试、Chromium 实际页面点击设置中心各分类、原生 Electron 真实 IPC 调用及主界面点击。无旧跳转卡片、无 React #185、无 IPC handler 报错。

## 约束

「定时发言」「商品弹窗」功能均需要平台适当授权和人工监督。此软件不自动在抖音平台开播/推流，也不绕过中控台权限。macOS ad-hoc 测试签名不是 Apple 正式公证。
