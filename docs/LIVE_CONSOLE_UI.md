# 单屏直播主控台（UI 交互重构）

## 设计目标

参考用户提供的「牛牛AI主播」布局，采用**左侧直播互动、右侧商品文案/主播要求/启动操作/常用配置**的密集双栏工作台。仅参考操作结构与交互层级，不复制原软件商标、素材或源代码。

- 默认入口：启动应用即进入 \`#/\` → 「AI 直播主控台」
- 顶部：当前账号、连接状态、高级设置
- 左侧：直播平台选择、连接/断开、弹幕/AI回复筛选、文字手动发送、语音插播
- 右上：当前商品选择、新增商品、商品名称/价格/库存、可编辑讲品文案（自动保存）
- 右中：主播回复人设/规则（直接修改原自动回复提示词）、一键开始/停止/紧急静音
- 右下：LLM 提供商、模型、系统或 MiMo 语音、主播音色、API Key、自动回复开关、手动录音插播和模拟弹幕
- 高级设置滑出面板：复用原 \`VoiceCommerce\` 完整功能，包括声音克隆、主播录音排期、商品知识库、视频素材/播放列表、OBS、库存、数据统计等

旧入口及原有功能不删，仍可经侧栏/旧页面访问。
\`#/live-control\` 为原中控台连接详情；\`#/voice-commerce\` 为旧全功能页。

## 操作验收路径（Windows）

1. **首次打开**：出现深色左右两列，没有宽侧边栏及 180px 底部日志；左侧显示“等待直播间互动”。
2. **切换账号**：顶部账号切换。不同账号商品配置、弹幕列表独立。切换账号后必须重新确认自动文字发送的授权，默认关闭。
3. **连接中控台**：左上选巨量百应/抖店等，点击“连接”，按原工具流程在 Chrome 登录。连接成功显示绿灯状态。
4. **维护商品**：点“新增商品”，填写名称、价格、库存、文案；切换商品再切回来确认内容持久保存。
5. **人设规则**：右侧输入简短回复要求，切换页面再回来内容保持。AI 自动回复会使用现有提示词。
6. **配置 Key**：点“密钥与模型”展开，分别配置 LLM、MiMo。Key 输入框为密码型；MiMo Key 经 Electron 主进程安全保存。
7. **开始播讲**：在连接的中控台上启动监听和辅助回复；如果已填商品则同时讲解，弹幕生成的新 AI 回复优先插播。若未配置 Key/连接，则显示明确错误信息。
8. **紧急停止**：点击“紧急静音”停止所有语音但不中断中控台；点“停止”终止评论监听及语音讲品，保持中控台登录。
9. **模拟问答**：填写问题后点“AI 生成”，可试听文字回复，但不会把模拟内容发送到平台。
10. **高级设置**：右上齿轮或底部链接打开侧面板；验证声音克隆、素材、OBS、库存、运营统计功能；关闭返回主台。

## 安全与平台约束

- 文字自动发送仍复用原项目中控台能力，不等于官方通用 API 权限。首页加载时将自动文字发送置为关闭；运营人员需要重新确认平台许可后才能主动开启。
- 手动发送提示“提交到中控台”，不谎称观众已收到。
- 不接入无人直播或绕过直播平台风控的功能；预录素材仅用于经许可的展示。
- 单屏主控台本身不要求额外 GPU；MiMo 云端语音需要有效 API Key/额度。
- GitHub Actions 编译及测试成功 != 真实 Windows/直播间端到端验收。
