# AI 语音带货：第一轮二开说明

本项目 Fork 自 [qiutongxue/oba-live-tool](https://github.com/qiutongxue/oba-live-tool)，保留原项目 MIT LICENSE 和版权声明。

## 已完成（MVP）

- 新增左侧「AI 语音带货」功能页；各账号商品资料独立持久化。
- 新增商品手动编辑、JSON 数组导入/导出；支持当前商品、已核实卖点、售价、库存和 FAQ。
- 复用项目现有 OpenAI 兼容模型配置与主进程 IPC，测试弹幕可生成 AI 文本回复。
- 使用 Windows/Chromium 系统自带的 speechSynthesis 进行语音播报，带队列、停止和语速配置，无需 GPU 或额外 API。
- 复用项目现有自动回复预览结果进行语音播报（需要在原有自动回复页面开启 AI 回复并成功监听）。
- 视频和主播音频本地素材预览（仅当前会话，不上传素材、不自动开播）。
- 提供将商品事实同步到现有「自动回复」AI 提示词的入口，**不会自动修改自动发言/自动发送权限**。

## 使用流程

1. 进入「AI 语音带货」，新建商品，填写准确售价/库存/卖点/FAQ，保存。
2. 在「AI 助手/自动回复」设置 API Key 和模型。这里复用原项目的自动回复模型配置。
3. 输入测试弹幕，点击「AI 生成」，核对文字回复后点击「语音播报」。
4. 在 Windows 音量混音器或虚拟音频设备中将应用的输出选为直播伴侣采集设备；先在线下测试确保没有回声。
5. 如果已有获得许可的直播中控台事件接入，在原「自动回复」页面连接并启动评论监听；然后打开本页面，开启「播报新产生的 AI 回复」，即可听到新回复；需要保持本页面打开。
6. 文字自动发送由**原项目的自动回复设置**控制，默认不主动启用；真实平台权限必须单独核实。

## JSON 导入示例

```json
[
  {
    "name": "示例商品",
    "price": "99元",
    "stock": "库存以实时商品页为准",
    "highlights": "材质：纯棉。尺码：M-XXL。",
    "faq": "问：是否包邮？答：以订单页显示的运费为准"
  }
]
```

## 局限及待办

- 当前使用 **Windows/Chromium 系统语音**，并非 MiMo 声音克隆；下一阶段通过 Electron 主进程集成可配置云端 TTS、音频设备选择和缓存。
- 导入的 MP3/MP4 仅本地预览，关闭页面需重新选择；暂未持久化文件或自动将视频推流。
- 文字发送依赖既有中控台接入机制，不等于官方授权。原项目使用的浏览器自动化需单独核验适用平台条款。
- 暂不支持无人值守的预录视频直播；请先确认平台直播规范。
- 商品数据暂为本地存储，不包含商品价格库存实时同步接口。
- 未经商家核验的信息一律不得由 AI 编造。
