# AI Live Commerce v0.3.0 – Independent development track

Branch: `feat/v0.3.0-one-click-live`. Based on v0.2.6 main @ `e33ddd21`.
Development package version: `0.3.0-alpha.2`. **Do not merge into main before an approved end-to-end acceptance.**

## Milestone A: OBS transport safety (implemented in alpha.1)
- Typed OBS transport preflight, StartStream/StopStream, status polling and account ownership.
- Refuses to take over an OBS stream started outside this app.
- Fails closed when OBS is not configured or stream is not confirmed.
- Stops only the stream started by the matching account/session.
- React settings has a read-only preflight button; there is **no one-click go-live button wired to actual streaming yet**.
- Tests use fake OBS transports; no platform credentials or real outbound RTMP traffic are used.

## Remaining milestones (NOT implemented yet)
- Managed OBS process startup/shutdown, persistent WebSocket/event updates.
- Browser Source for image/video playlist; local loopback media server and protected URLs.
- Route verified TTS audio into the OBS mixer, not just Electron speakers.
- Integrate all readiness checks and lifecycle into the main one-click Start/Stop UI.
- Native OBS and local RTMP reception, duration/video/audio track verification on Windows and macOS.
- Failure recovery, controlled stop, video/audio diagnostics and long-running tests.
- Actual Douyin go-live and comment permissions **only** with appropriate platform authorization.

These tasks are deliberately separate so a successful alpha.1 CI does not masquerade as a tested live broadcast.

## Milestone B: image media and native OBS checks (alpha.2)
- Import/preview JPG/PNG/WebP along with existing videos, with file-size and MIME allowlists.
- Extend native Electron mock OBS integration to exercise stream preflight, StartStream and StopStream with ownership protection.
- The local OBS Browser Source bridge, AI audio mixing and true one-click main UI remain unfinished.
