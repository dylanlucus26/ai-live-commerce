# AI 语音带货 —— 本轮软件功能交付范围

原项目与授权条款见主仓库 README/LICENSE。本版本为运营辅助工具，不能绕过平台授权或作为无人录播合规依据。

## 新功能（feat/voice-commerce-complete）

1. **主播声音克隆闭环修复**：设置中启用已授权样本后，播放器传递 \`cloneAccountId\` 到 Electron MiMo TTS，选择 \`mimo-v2.5-tts-voiceclone\` 模型，Windows 本机加密存储参考音频。参考 [官方说明](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/audio/speech-synthesis-v2.5)。
2. **关键词 + AI 统一回复记录**：关键词命中也写入原自动回复历史，应用级统一声音队列自动播报新回复。与原版兼容的自动文字发送仍由原设置控制，是否允许运营自动化须先核实中控台权限。
3. **文字发送确认分级**：区别 \`请求已提交\`、\`中控台任务接受\`、\`调用失败\`；不能把中控台返回接受当作平台投递或观众收到消息的证据。
4. **应用级运行时**：VoiceRuntimeHost 挂在 Electron App 根节点，页面导航不再中断播报、录音排期、库存轮询。每次启动软件或切换账号时需要人工重新启用排期和库存轮询，避免无意后台播放。
5. **商品视频列表**：从本地素材库选择视频、排序、删除、手动切换；可开启页面预览下一条衔接。不会把视频自动推送到抖音或启动录播直播。
6. **运营统计**：各账号保存最近 7 天（最多 500 条）评论、回复生成、文字请求接受/失败、语音完成/错误等，不保存弹幕正文/昵称，可导出 CSV；未集成平台 GMV、真实送达率或计费明细。
7. **授权库存适配**：保留原商家 CSV/JSON 文件源，新增仅允许连接本机 \`127.0.0.1:<PORT>/inventory\` 的授权 ERP/OpenAPI 桥接入口，由商家有权调用的平台 SDK/ERP 服务自己完成鉴权签名。禁止抓 Cookie、模拟不受许可的接口或向任意网站发送商家凭据。

## 本地桥接协议

\`GET http://127.0.0.1:18080/inventory\`

\`\`\`json
{
  "products": [
    { "sku": "SKU001", "name": "商品A", "price": "99元", "stock": "20" },
    { "sku": "SKU002", "price": "199元", "stock": "库存以商品页为准" }
  ]
}
\`\`\`

不接受重复 SKU，最多 500 条。收到的数据仅按已有商品 SKU 更新真实价格/库存，不修改商品卖点、促销话术、素材。要直连抖音电商开放平台，需商家提供 **获批应用、有效 scopes、签名/鉴权文档及测试环境**，届时在授权桥接层实现；本仓库未伪造不存在的官方权限。

## 自动化测试范围和现实限制

CI 包含 Windows TypeScript 类型检查、Node 单元测试和 Electron Windows 安装包构建。

**CI 无法替代**：MiMo 付费接口实际试听、公司 Windows 虚拟声卡路由、OBS 连接、抖店/巨量百应直播中控台评论和文字发送权限、实时库存 API 授权、8～12 小时直播稳定性、数据保护与主播授权证明。

商用前需要配置真实权限、遵守 AI 内容标识要求，并由运营人员值守/具备人工接管。
