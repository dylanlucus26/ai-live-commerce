# v0.2.5 完整设置中心布局回归

## 已定位根因

liveWorkbench.css 和 advancedSettings.css 在同一全局 CSS 作用域中，均定义了 .live-settings-grid。
主控台使用四列，而设置中心使用两列，CSS 引入顺序使四列覆盖设置中心，导致部分页面的前两张卡片仅占左半区域，而右半大面积空白。

## 修复

1. 重命名主控台 `.live-settings-grid` → `.live-quick-settings-grid`，两套样式完全隔离；设置中心仍使用 `.live-settings-grid`，不再受主控台四列规则影响。
2. 统一设置中心卡片网格：正文占满容器，两列各占 1fr，宽卡片跨两列；可用区域过窄时自动单列，表单及统计同样响应式。
3. 防止头部、按钮组、输入框、统计卡片横向溢出。
4. 新增 9 个设置分类 × 1920 / 1440 / 1024 三种分辨率全量 Playwright 审计（27 张截图另加三个主控台截图）。
5. 检查所有设置页网格填满正文宽度、最右卡片到达正文右边缘、无横向滚动、无子卡片溢出；错误信息会直接写入 CI 日志并保存失败截图。
6. 构建保留原生 Windows/macOS Electron 启动与 IPC 测试、签名检查、鼠标拖拽窗口检查。

## 限制

云端真实浏览器与 Electron 自动化不能保证所有操作系统字体、所有视频源和第三方接口都已完全实测。Mac 上的最终手感仍需用户安装验收。不要再把单一编译通过表述为全功能完美交付。
